## Projects

- **[Kernel Keeper](https://github.com/cla1redonald/kernel-keeper)** checks a team's AI memory, and the skills and agents that act on it, for rot. AI drafts the fixes, but nothing changes until a named person has signed one off, and then a deterministic clerk applies it. It is a companion to team-os.
- The **[ABE kit](https://github.com/cla1redonald/ai-business-enablement)** is a two-week AI readiness diagnostic. Skills write the drafts and scripts check them, and the consultant makes the decisions. It runs end to end on an invented freight company in about a minute.
- **[Ghillie](https://github.com/cla1redonald/highland-games-rota)** keeps a Highland games volunteer rota accurate from the committee's chat, mail and minutes, and only bothers the organiser when it has to. It is built three ways on one MCP server, by hand on the Messages API, on the Agent SDK and on Managed Agents, and each version is measured live against the same cases. The comparison page says what each layer did, what broke and when you would pick it. Everyone in it is fictional.
- **[Agent Casebook](https://github.com/cla1redonald/agent-casebook)** is a casebook of broken AI agents. Each of its nine cases was recorded live and has six suspects. You unlock the sealed solution by accusing the right suspect with the evidence, and every case comes with a detector you can run over your own traces.
- **[Harbourlight](https://github.com/cla1redonald/harbourlight)** is a governed content pipeline for an invented regulated mutual. It researches and drafts posts, an independent compliance reviewer checks them and quotes its evidence, and then they wait in a queue for a person to approve them. Everything goes in an audit log, and evals measure the reviewer. On 24 labelled posts, Haiku 5.5 catches 20 of 20 hard-rule breaches at a tenth of a cent each. Everything in it is fictional.
- **[ProveIt](https://github.com/cla1redonald/proveit)** tests a product idea before you build it, using structured discovery, market and competitor research, an adversarial swarm and a falsifiable pre-mortem. It is a Claude Code plugin and a web app, and the web app is [live](https://proveit.tools).
- **[FocusBoard](https://github.com/cla1redonald/focusboard)** is a Kanban board where cards are written in plain language and captured from several channels. It has WIP limits and a metrics dashboard, and an MCP server sits behind its claude.ai connector.
- **[ShipIt v4](https://github.com/cla1redonald/shipit-v4)** is a build workflow for Claude Code. Its quality gates and its learning loop are enforced by hooks and CI instead of by written instructions.
- **[team-os](https://github.com/cla1redonald/team-os)** is the shared context a team's AI runs on, set out as a worked example for an invented open-finance company that you can fork.
- **[self-improving-skill-agent](https://github.com/cla1redonald/self-improving-skill-agent)** uses Managed Agents to rework a skill against a deterministic eval until it clears a pass-rate target.
- **[skill-review](https://github.com/cla1redonald/skill-review)** is a skill that reviews other skills before they go into an internal marketplace. A free, deterministic pre-check runs before it.
- **[agent-sandbox](https://github.com/cla1redonald/agent-sandbox)** runs AI coding agents on a local model inside a kernel-level sandbox, so the work stays private, runs offline and costs nothing in API fees.
- **[claude-html-deck](https://github.com/cla1redonald/claude-html-deck)** makes executive-grade HTML slide decks from Claude Code. You can re-skin them and print them, or deploy them behind a password.
- **[de-ai-ify](https://github.com/cla1redonald/de-ai-ify)** strips AI-sounding jargon out of text. It comes as a Word plugin and a [web tool](https://de-ai-ify.vercel.app).
- **[streamdeck-claude](https://github.com/cla1redonald/streamdeck-claude)** puts Approve and Deny for Claude's tool calls on a physical Stream Deck button, with a small local broker and an MCP server in between.
- **[Weather Mood](https://github.com/cla1redonald/weather-mood)** paints a city's live weather as generative art, with a poem read aloud over music. The fun one. [Live](https://weather-mood-chi.vercel.app).
- **[claude-spinner-themes](https://github.com/cla1redonald/claude-spinner-themes)** adds Scottish themes to Claude Code's thinking spinner. It has 160 verified Scottish words, each with an emoji matched to its meaning, and a safe one-line switcher.
